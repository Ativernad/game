# Попіл Світанку

Невелика дарк-фентезі RPG від першої особи (~20 хвилин) на **Godot 4.7.2** для Windows і macOS.
3D-локації, 2D-предмети, вороги 2.5D: кожен ворог складається з кількох 2D-шарів
(тіло, броня/одяг, зброя), розставлених у глибину. Шари перевикористовуються:
скелет-воїн і скелет-лучник мають однакове тіло, але різну зброю й одяг.

Уся графіка (піксель-арт) і звук (ембієнт-музика, ефекти) генеруються кодом,
тож проєкт запускається без жодних зовнішніх ресурсів.

## Запуск
Відкрий папку в Godot 4.7.2 → **F5**.

## Шлях гравця
1. Мертвий ліс → 2. Руїни каплиці (ключ від ґрат) → 3. Підземелля — **бос: Кістяний Сторож** →
4. Ущелина → 5. Катакомби (ключ від крипти) → 6. Мертве місто (зомбі) →
7–11. Замок: хол, великі сходи, бібліотека алхіміка (печатка), туманні сходи, коридори →
12. Тронна зала — **бос: Принц Вічної Ночі** → фінал: балкон і світанок.

## Класи (карти таро)
| Карта | Клас | ЛКМ / RT | ПКМ / LT |
|---|---|---|---|
| VII Колісниця | Лицар | удар мечем | блок щитом |
| XVIII Місяць | Лучниця | натягнути й випустити стрілу | кинджал |
| 0 Блазень | Жебрак | удар палицею | ривок-ухилення (невразливість) |

Жебрак частіше знаходить додаткові предмети.

## Керування
| Дія | Клавіатура / миша | Контролер |
|---|---|---|
| Рух / огляд | WASD / миша | лівий / правий стік |
| Біг, стрибок | Shift, Пробіл | L3, A |
| Взаємодія | E | X |
| Швидке лікування | Q | Y |
| Інвентар | Tab / I | Back |
| Пауза | Esc | Start |

## Структура
```
scripts/autoload/  settings.gd (налаштування + карта керування), audio.gd (процедурний звук), game.gd (стан, інвентар, збереження)
scripts/core/      level_db.gd (усі карти локацій), item_db.gd (предмети), art.gd + px.gd (генерація піксель-арту)
scripts/world/     world.gd (ігрова сцена), level_builder.gd (3D з сітки), скрині, ґрати, вихід, фінал
scripts/player/    player.gd (рух, бій, вид зброї), projectile.gd
scripts/enemies/   enemy.gd (типи ворогів, шари, ШІ, боси)
scripts/ui/        меню, карти таро, інвентар, налаштування, HUD
shaders/retro.gdshader  ретро-фільтр (вмикається в налаштуваннях)
```

## Як розширювати
- **Свої малюнки**: поклади PNG у `res://art/<назва>.png` — він автоматично замінить
  згенерований (назви: `skel_body`, `w_bow`, `prince_body`, `card_knight`, `icon_herb`, `stone`, …
  див. `Art._build`).
- **Нова локація**: додай словник у `LevelDB.LEVELS` — карта малюється символами
  (легенда на початку файлу), висоти/сходи — рядками `heights`.
- **Новий ворог**: запис у `Enemy.TYPES` зі списком шарів, напр.
  `["skel_body", "hood", "w_staff"]` — скелет-маг з наявних шарів.

## Налагодження
```
Godot --path . res://scenes/game.tscn -- --level=7 --class=archer
```
відкриває одразу потрібну локацію (0–11) потрібним класом.

## Експорт
Project → Export → додай пресети **Windows Desktop** і **macOS** (потрібні export templates 4.7.2).
Збереження й налаштування лежать у `user://` (save.json, settings.cfg).
